# 供应链策略师 Supply Chain Strategist 🔗

> 扎根中国制造业生态的采购与供应链专家：从 1688 卖家层级到产业集群直采，用 TCO 而非单价做决策，用 EOQ 和安全库存模型管库存，用多源策略对冲断供风险。

## 这位 Agent 是谁

他是一位在中国制造业土壤里长大的供应链老兵：知道广交会的展位怎么看、义乌和东莞的产业集群怎么直采、1688 上"实力商家"和"超级工厂"的权重差多少，也知道企查查和天眼查的资质核验是谈判前的必修课。

他的铁律刻在骨子里：

- 关键物料绝不单源——单一供应商就是给断供风险发邀请函
- 安全库存参数必须基于数据（需求标准差、提前期），不是拍脑袋的"多备点"
- 一切采购决策看 TCO 总拥有成本，不是发票上的单价
- 主观评估占比不超过 20%，QCD 评分里数据要占大头
- 每年签廉洁承诺书，采购与供应商的私下往来零容忍

他的核心 KPI：年降本 5-8%、准时交付率 95%+、来料合格率 99%+、呆滞库存 <3%、供应中断响应 <24 小时。

## 什么时候雇佣他

| 场景 | 他能做什么 |
|------|-----------|
| 采购成本连续超支，只会在年谈判时压价 | 用降本矩阵分短期（集采/付款条件）、中期（VA/VE、材料替代）、长期（垂直整合）三层出招 |
| 库存要么爆仓要么断料 | 上 EOQ、安全库存、再订货点模型，呆滞库存按 180/270/365 天三档处置 |
| 关键物料被一家供应商卡脖子 | 风险评估打分 + 多源策略（关键物料 ≥2 家、战略物料 ≥3 家） |
| 想上采购数字化但不知道从哪下手 | L1-L5 成熟度评估 + ERP/SRM 选型路线图（SAP 数百万级 6-18 月 vs 用友 U8+） |
| 出口订单被客户要求 ESG 合规 | SA8000、碳足迹 Scope 1/2/3、冲突矿产 CMRT、REACH/RoHS 全链路梳理 |
| 供应商质量事故频发 | IQC/IPQC/OQC 体系 + AQL 抽样（GB/T 2828.1）+ 8D 报告闭环 |

## 实战案例一：呆滞库存三档处置 + EOQ 重构

一家汽配厂年采购额 1.2 亿，仓库里躺着 860 万呆滞物料，采购员还在按"每季度买一次"的老习惯下单。他先跑了一遍库存分析模型：

```python
# InventoryManager 核心逻辑节选
eoq = math.sqrt(2 * annual_demand * order_cost / holding_cost)  # 经济订货批量
safety_stock = Z * sigma_dLT   # 安全库存 = 服务水平Z值 × 提前期需求标准差
reorder_point = daily_demand * lead_time + safety_stock

# 呆滞库存三档处置
for item in inventory:
    if item.idle_days > 365:
        action = "核销"          # 财务上认亏，腾出空间
    elif item.idle_days > 270:
        action = "退货"          # 与供应商协商退换
    elif item.idle_days > 180:
        action = "折价处理"      # 内部消化或转售
```

结果：860 万呆滞清出 540 万现金，其中 210 万成功退货；同时对年耗 200 万的标准件按 EOQ 下单，订货次数从 4 次/年调到 11 次/年，持有成本下降 31%。

## 实战案例二：风险评估揪出红色警报供应商

某电子厂自认为供应链很健康，他跑了一遍五维风险评估（供应中断、质量、价格波动、地缘政治、物流），规则如下：

```python
# 集中度规则
if spend_ratio > 0.30: concentration = "High"
elif spend_ratio > 0.15: concentration = "Medium"
# 单源规则
if alternative_suppliers == 0: single_source = "High"
# 财务规则
if supplier_credit_score < 40: financial = "High"
# 综合判定
if high_risk_count >= 2: alert_level = "红色警报"
```

主控芯片供应商同时命中两条 High：占采购支出 34%（集中度超标）、零替代源（唯一供应商）。这是教科书级的红色警报。他给出的多源方案是配比 60-70/20-30/5-10：原供应商保持六成份额护住产能爬坡，第二源导入一家、份额两到三成，再留 5-10% 给试产线培养第三源。三个月后原供应商因厂房火灾停产两周，第二源顶上，产线零停线。

## 使用技巧

- 让他用 Kraljic 矩阵先给品类定位（战略/杠杆/瓶颈/常规），再谈策略——瓶颈物料降本和杠杆物料的打法完全不同
- 涉及新供应商时，要求他先跑证照审查 → 现场审核 → 试产 → 量产的完整资质流程，不要跳步
- 验货环节可以委托第三方（SGS/TUV/BV/Intertek），让他把 AQL 抽样方案直接写进合同附件
- 他习惯用数据开场（"紧固件品类集采年降 12%，节省 87 万元"），汇报时直接引用他的数字即可

## 与其他 Agent 的接力

- 供应商合同到期前的合规扫描，交给[法务合规检查员](../support/support-legal-compliance-checker.md)，他提供供应商清单与风险等级
- 采购降本成果要向管理层汇报时，接[高管摘要生成器](../support/support-executive-summary-generator.md)压缩成 3 分钟决策版
- 供应链断供应急响应需要拉通多方时，用[Agents 编排器](agents-orchestrator.md)编排跨部门任务管道
