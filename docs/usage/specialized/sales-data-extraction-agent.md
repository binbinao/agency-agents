# 销售数据提取代理（Sales Data Extraction Agent 📊）

> 盯着你的 Excel 目录，新文件一落地就抽出 MTD/YTD/年终预测指标入库，全程留痕、绝不覆盖。

## 这位 Agent 是谁

销售数据提取代理是特殊专家部门的数据管道专家，人设是一名"一个数据点都不许丢"的管道工程师。他是销售报告三件套（提取 → 汇总 → 分发）的第一环：监控指定目录里的 Excel 文件，实时解析出月度至今（MTD）、年度至今（YTD）、年终预测三类指标，规范化后写入 PostgreSQL 供下游使用。

五条关键规则：

- **绝不覆盖**：没有明确的更新信号（新文件版本）不动已有指标。
- **记录一切**：每次导入登记文件名、处理行数、失败行数、时间戳。
- **按邮箱或全名匹配销售代表**：匹配不上的行跳过并告警，绝不猜。
- **弹性列映射**：模糊匹配 `revenue/sales/total_sales`、`units/qty/quantity` 等变体列名。
- **从工作表名识别指标类型**：MTD/YTD/Year End，无法识别时用合理默认值。

核心 KPI：有效 Excel 文件 100% 无人工干预处理、格式良好的报表行级失败率 < 2%、单文件处理 < 5 秒、每次导入完整审计留痕。

## 什么时候雇佣他

| 场景 | 典型需求 | 他的做法 |
|------|----------|----------|
| 各区域销售发 Excel 周报格式不一 | 自动入库 | 文件系统监听 + 弹性列映射 + 事务写入 |
| Excel 版本混乱怕覆盖旧数据 | 数据安全 | 新版本信号检测，绝不静默覆盖 |
| 货币符号、千分位干扰数字解析 | 清洗 | 自动剥离 $、逗号等格式字符 |
| 手动录入总是漏人 | 完整性 | 未匹配代表逐行告警，宁可停一行不吞一行 |
| 下游仪表盘要新鲜数据 | 实时性 | 文件写完即处理，完成事件通知下游 Agent |

## 实战案例：七个区域、三种格式的周报统一

某制造企业的七个大区销售每周五花式提交周报：有的叫 `Revenue` 列，有的叫 `Total Sales`，有的把 MTD 和 YTD 放在同一张表用两列区分，还有一个区习惯把指标藏在第二个工作表。过去由一名运营专员每周一上午手工录入，平均耗时 3 小时且每季度总会错录两三行。

提取代理上线后的处理流程（还原）：

```text
1. 文件系统监听器发现新 .xlsx（忽略 ~$ 临时锁文件，
   等待写入完成再处理）
2. 登记导入状态为 "processing"
3. 遍历所有工作表，逐表识别指标类型
   - 表名含 "MTD" → month_to_date
   - 表名含 "YTD" → year_to_date
   - 表名含 "Year End" / "Forecast" → year_end_projection
   - 无标识 → 默认 month_to_date 并在日志标注 "assumed"
4. 弹性列映射：
   revenue | sales | total_sales  →  revenue
   units | qty | quantity        →  units
   quota | target               →  quota
5. 按邮箱/全名匹配销售代表，未匹配行跳过 + 告警
6. 剥离 "$1,234.5" 中的 $ 和逗号 → 1234.5
7. 事务性批量插入 PostgreSQL，每行指标记录来源文件名
8. 更新导入日志，向下游发出完成事件
```

上线首月日志显示：处理成功率 100%，行级失败率 0.7%（全是人名打错导致的匹配失败，告警后当周修正），单文件处理平均 4.2 秒。运营专员的工作从 3 小时录入变成 10 分钟看告警。给下游的完成事件触发了数据汇总代理自动刷新仪表盘，整个链条从"周一上午才有上周数据"变成"周五下班前数据已上线"。

## 实战案例：一次差点发生的覆盖事故

华东区经理重发了一份"更正版"周报，但文件名和上周完全相同（从邮件另存为时覆盖了旧文件）。代理的处理体现了"绝不覆盖"规则的实现层次：先按"来源文件名 + 内容指纹"比对库内记录，检测到行数一致但 3 行数值不同——这不是新版本信号的典型模式（正常更正版会带 v2 或日期变化），于是按规则挂起该导入、标记"疑似重复文件、数值冲突"，向管理员告警。管理员确认这是更正版后手动放行，且旧值以历史版本形式保留而非抹掉。事后审计时，那 3 行改动恰好是一处真实的录入更正——代理既没吞掉更正，也没毁掉历史。

## 使用技巧

- 给他一份"代表名录"作为匹配基准：邮箱优先于全名，重名场景必须用邮箱。
- 约定文件命名含日期或版本：这是他的"更新信号"，命名混乱会频繁触发挂起告警。
- 让告警有去处：未匹配行、疑似冲突如果没有负责人看，规则就白定了。
- 与下游打通完成事件：他的价值一半在提取，一半在"提取完立刻有人知道"。
