# 数据汇总代理（Data Consolidation Agent 🗄️）

> 把提取入库的散乱销售指标聚合成实时仪表盘：区域汇总、代表排名、管道快照、六个月趋势，加载不到 1 秒。

## 这位 Agent 是谁

数据汇总代理是特殊专家部门的战略数据合成器，人设是一名"既懂数字又懂呈现"的分析型工程师。他是销售报告三件套的中间环：上游是销售数据提取代理（负责把 Excel 入库），下游是报告分发代理（负责把报告送到每个人邮箱）。他的职责是把原始指标加工成仪表盘友好的结构化视图。

五条关键规则：

- **永远用最新数据**：每类指标按 metric_date 取最新一条，绝不拿旧值冒充现值。
- **达标率精确计算**：revenue / quota × 100，除零必须处理（无配额的代表显示 N/A 而非报错）。
- **按区域聚合**：指标按区域分组，保证区域视角的可见性。
- **管道数据必须合并**：线索管道与销售指标合在一起才是完整画面。
- **多视图随取**：MTD、YTD、年终汇总按需切换。

核心 KPI：仪表盘加载 < 1 秒、报告每 60 秒自动刷新、所有活跃区域与代表全覆盖、明细视图与汇总视图零数据不一致。

## 什么时候雇佣他

| 场景 | 典型需求 | 他的做法 |
|------|----------|----------|
| 管理层要一页看懂全国销售盘 | 仪表盘报告 | 区域汇总 + 代表排名 + Top 5 + 六个月趋势 |
| 区域经理只关心自己辖区 | 区域深度报告 | 单区域下钻：全部代表 + 最近 50 条指标历史 |
| 周会要"管道健康吗"这个问题有答案 | 管道快照 | 按阶段统计数量、金额、加权金额 |
| 汇总数对不上明细被质疑 | 一致性 | 明细与汇总同源同算，结构上杜绝两张皮 |
| 报告要嵌入别的系统 | 数据交付 | 仪表盘友好 JSON + 生成时间戳 |

## 实战案例：一个"总销售额对不上"问题的结构性根治

某企业用老 BI 工具时，销售 VP 每周的固定质疑是："你报表说全国 YTD 是 $4.2M，我把七个区域的数加起来是 $4.35M，哪个对？"数据团队每次都要花半天排查，结论通常是"有个区域提交的是更正前的旧数"。汇总代理接入后，这类质疑消失了，原因藏在两条规则的组合里：

```text
规则 1 —— 永远用最新数据：
  每类指标按 (representative, metric_type) 取 metric_date 最大的一条。
  区域更正重发 Excel → 提取代理入库新记录 → 汇总自动切换到新值，
  旧值降为历史，不再参与任何聚合。

规则 2 —— 明细与汇总同源：
  全国汇总 = 对全部代表执行同一聚合查询；
  区域汇总 = 同一查询加 WHERE territory 条件；
  代表明细 = 同一查询加 WHERE rep 条件。
  三级视图出自同一 SQL 逻辑，数学上不可能对不上。
```

同时每份报告附带生成时间戳（staleness detection）：管理层打开仪表盘能看到"数据截至 60 秒前"，再也不用猜这是不是今早的版本。数据团队的半天排查时间归零，这还没有算上信任成本——当数字长期对得上，会上花在质疑数据的时间也省了。

## 实战案例：管道快照改写了一次资源分配决策

某季中复盘会，管理层原计划给 YTD 达标率最高的区域追加两个招聘名额。汇总代理的管道快照让这个决定被推翻（表格还原）：

| 阶段 | 商机数 | 总金额 | 加权金额 | 加权系数 |
|------|--------|--------|----------|----------|
| 初步接触 | 84 | $2.1M | $210K | 0.10 |
| 需求确认 | 41 | $1.8M | $540K | 0.30 |
| 方案报价 | 18 | $1.5M | $750K | 0.50 |
| 谈判签约 | 7 | $900K | $675K | 0.75 |

达标率第一的区域管道快照显示：其商机 76% 堆在"初步接触"阶段，加权管道仅覆盖下季度目标的 61%——高达标率吃的是存量，后继乏力。而排名第三的区域 52% 的加权管道已推进到报价与签约阶段。名额最终给了后者，季度末结果验证了判断：前者环比下滑 9%，后者环比增长 23%。管道快照的价值在于它回答的是"未来"，而达标率排名回答的只是"过去"。

## 使用技巧

- 配合上游约束数据质量：他的准确性完全取决于提取代理入库的规则执行，两个一起部署。
- 仪表盘刷新别高于数据更新频率：数据 60 秒入库一次，仪表盘 5 秒刷新只是自我安慰。
- 加权系数要业务校准：默认 0.10/0.30/0.50/0.75 应按本团队历史转化率修正。
- 多视图按需取用：MTD 看冲量、YTD 看大盘、年终预测看趋势外推，别只用一个。
