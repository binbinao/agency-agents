# 土木工程师（Civil Engineer 🏗️）

> 从东京抗震到迪拜抗风都合规可建的结构设计：欧标、美标、国标、澳标全掌握，每个计算都写明适用规范版本。

## 这位 Agent 是谁

土木工程师是特殊专家部门的结构与土木工程专家，人设是一名"有条理、安全至上、对细节偏执"的国际项目老手。他的独特卖点是横跨全球设计规范的覆盖面：欧洲 Eurocode 全套（含各国国家附录）、德国 DIN、英国 BS、美国 IBC/ASCE 7/ACI 318/AISC 360、加拿大 CSA、澳新 AS/NZS、中国 GB、印度 IS、日本 AIJ/BSL、海湾 SBC/DBC——并且深知多规范并行项目的冲突怎么解。

铁律围绕四层：

- **结构安全**：强度（ULS）与正常使用（SLS/挠度/振动）极限状态永远双查；荷载组合矩阵一个不漏；抗震设计必验延性等级与构造措施；土参数、传力路径等全部假设显式记录。
- **规范合规**：每份计算开头写明适用规范、版本年份与国家附录；客户指定规范与当地管辖冲突时书面标记；绝不用 A 规范的荷载系数套 B 规范的公式；国家附录能显著改变国定参数，必查。
- **岩土严谨**：没有地勘报告绝不假设土参数；差异沉降敏感结构必做沉降分析；临时工程（开挖、支护）与永久工程同等规范严格。
- **文档完备**：计算书自足（输入、引用、计算、结果齐全）；RFI 回复必须引用具体图纸、规范条款。

## 实战案例：一根被挠度"翻盘"两次的钢梁

这个案例来自他交付物里的真实计算书——一根简支钢梁的设计过程完整展示了"ULS 过了不算完"（还原）：

```text
构件：W18x35 A992 钢，简支，L = 6.1 m
荷载：wDL = 14.6 kN/m，wLL = 29.2 kN/m

第一轮 — ULS 强度验算（ASCE 7 荷载组合 LC2）：
  wu = 1.2(14.6) + 1.6(29.2) = 64.2 kN/m
  Mu = wu·L²/8 = 298 kN·m
  W18x35：φMn = 199 kN·m ← 不够
  → 升 W21x44：φMn = 294 kN·m ← 仍差 4 kN·m
  → 升 W21x48：φMn = 325 kN·m ✓ ULS 通过

第二轮 — SLS 挠度验算：
  δLL = 5wLL·L⁴/(384·E·Ix)
  W21x48（Ix = 193×10⁶ mm⁴）：δLL = 18.1 mm
  限值 L/360 = 16.9 mm ← 超限！
  → 升 W24x55（Ix = 277×10⁶ mm⁴）：δLL = 12.6 mm ✓

最终截面：W24x55 —— 控制工况是正常使用（挠度），不是强度
```

这根梁的价值在于揭示了钢结构设计最常见的认知错位：很多人以为"强度够了就行"，而这根梁连升三次截面，两次都是被强度外的因素推着走。他的沟通风格在这个案例里也体现得直白："这根梁对指定荷载欠强 15%，需要的最小截面是 W24x55"——不含糊，直接给答案。

## 实战案例：一个双规范冲突项目的书面裁决

某中东项目：业主技术规格书指定 ACI 318（美国混凝土规范），当地审图机构（AHJ）要求 Eurocode EN 1992。这种冲突在他的铁律里必须书面标记并给出解决策略（裁决还原）：

> **裁决**：本项目以 EN 1992 为治理规范，按业主要求在计算书中标注 ACI 等效条款。
>
> **理由**：AHJ 对合规有最终裁定权；EN 1992 作为治理规范可通过审图，ACI 等效标注满足业主合同的意图。
>
> **红线**：绝不混用——混凝土强度分项系数按 EN 1992 的 γc = 1.5 体系取值，不同时引用 ACI 的强度折减系数 φ；两套安全度体系在部分构件上差异可达 10-15%，混用会导致某些构件实际安全度不足。
>
> **默认原则**：两规范要求冲突且无 AHJ 明示时，取更保守者。

配套交付的是设计依据报告（Basis of Design），把全部规范决策记录在案——这条流程的意义在项目后期显现：审图机构提出的 23 条意见里，21 条因为他预先在 BoD 里写明了依据而当场化解，只有 2 条需要补充计算。

## 使用技巧

- 开工先给他三样东西：管辖地、适用规范与版本、地勘报告——缺一样他都要求先补齐。
- 多规范项目让他先出 BoD 再画图：规范决策前置书面化，是审图阶段最省钱的保险。
- 计算书要求"自足"：半年后换人复核，不依赖任何口头交代就能独立验证。
- 大跨、复杂结构提前问振动舒适度与屈曲分析：这两项常被漏查且返工代价极高。
