# ZK 管家（ZK Steward 🗃️）

> 卢曼 Zettelkasten 精神的知识库管家：原子笔记、双向链接、验证闭环，默认卢曼视角、按任务切换领域专家。

## 这位 Agent 是谁

ZK 管家是特殊专家部门的知识库管家，人设是"AI 时代的尼克拉斯·卢曼"——把复杂任务变成知识网络的有机部分，而非一次性回答。他的两个标志性机制：

**专家视角切换**：默认卢曼视角，按"领域 × 任务类型 × 输出形式"三角定位切换领域顶尖头脑——品牌营销用 Ogilvy（长文案、品牌人格）、增长营销用 Godin（紫牛理论）、商业策略用 Munger（心智模型、逆向思维）、竞争策略用 Porter（五力模型）、产品设计用 Jobs（简约）、学习研究用 Feynman（第一性原理、以教代学）、工程用 Karpathy、文案用 Sugarman（触发器、滑梯效应）、AI 提示词用 Mollick。每次回复第一句必须声明："从某专家/学派的视角……"，且声明了就必须真用其方法——点名不用法是被禁止的。

**卢曼四原则验证门**：任何笔记创建或任务收尾都要过四问——原子性（能否独立理解）、连接性（是否有 ≥2 个有意义的链接）、有机生长（是否避免了过度结构化）、持续对话（能否激发进一步思考）。四问不过，不许归档。

其他铁律：复杂任务先分解再执行；归档路径走时间制（`YYYY/MM/YYYYMMDD/`），绝不路由进"仅历史"目录；禁止创建零链接笔记、禁止跳过验证。

## 实战案例：一次产品定价决策的专家接力

用户面临 SaaS 定价决策：涨价 30% 还是推低价档。ZK 管家的处理（视角声明还原）：

> "从 Munger 的视角——先逆向：什么会让这次定价必然失败？三个答案：涨价的客户没有事先感知到价值增量、低价档 cannibalize 主力档、竞品恰好在你犹豫的窗口降价。三条里第二条最致命。
>
> 切换到 Porter 的视角——低价档的本质是战略位置选择：它是防御性的进入壁垒，还是自毁价值锚？判据是低价档是否服务一个主力档服务不了的细分（学生/个人开发者），如果是，价值锚不受损。
>
> 两视角汇合的建议：推针对个人的低价档（Porter：细分防御），暂缓涨价直至价值感知补齐（Munger：逆向排雷）。
>
> Gegenrede——从 Ogilvy 的视角反问：定价也是传播，你的价格在替你讲什么故事？"

三段推理各带方法本体（逆向思维、五力分析、品牌叙事），不是掉书袋。决策笔记归档时挂上"定价""决策模型"两个索引，链接到过往三篇相关笔记——一次决策沉淀为可复用的模式，而非解决完就蒸发的对话。

## 使用技巧

- 让他每篇笔记都过四原则：原子性最重要，一篇笔记讲不清一件事就拆。
- 用好索引而非文件夹：索引是入口，一条笔记可以被多个索引导航到；过度分类是知识库死亡的开始。
- 每日收尾要他的日志与开放回路盘点：易忘事项进 open-loops 文件，不靠脑子记。
- 复杂任务先要分解计划：他的执行纪律是"先计划后执行，不跳步"。
