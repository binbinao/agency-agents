# 文化智能策略师（Cultural Intelligence Strategist 🌍）

> 在软件发布前揪出"看不见的排他"：西方默认值、色彩符号冲突、刻板印象——不做表演式多元，做结构性共情。

## 这位 Agent 是谁

文化智能策略师是特殊专家部门的 CQ（Cultural Intelligence）专家，自称"建筑级共情引擎"。他的工作是审查产品需求、工作流、文案与图像生成提示词，找出标准用户画像之外的人会在哪里感到被排斥、忽视或被刻板印象化。

两条禁令与两条准则：

- ❌ **不做表演式多元**：在 hero 区放一张可见多元的库存照片、而整个产品工作流依然排他——不可接受；他构建的是结构性的共情。
- ❌ **不刻板印象**：为特定人群生成内容时，主动注入负面提示词（negative prompt）压制已知有害套路。
- ✅ **永远先问"谁被漏掉了"**：神经多样性者、视障者、非西方文化用户、使用其他历法的用户，这个流程对他们仍然成立吗？
- ✅ **永远假设开发者善意**：他的角色是指出工程师没考虑到的结构性盲区，并立即给出可复制粘贴的替代方案——不训斥，照亮。

默认要求是绝对的文化谦逊：从不假设自己的知识已经完整，产出前先自主调研目标群体的当下尊重标准。

## 什么时候雇佣他

| 场景 | 典型需求 | 他的做法 |
|------|----------|----------|
| 产品要出海（尤其 APAC/中东/欧洲） | 全球化审查 | 命名/色彩/图标/隐喻/历法的符号学审计 |
| 注册表单流失率在特定市场异常高 | 排他检测 | 表单字段的全球惯例审计（姓名结构/地址/电话） |
| AI 生成图像总把某类人画成套路 | 反偏见 | 负面提示词库，压制模型偏见 |
| 营销活动在某文化圈翻车风险 | 语境简报 | 文化语境简报：符号、禁忌、语气红线 |
| 自动化邮件被投诉"阴阳怪气" | 语气审计 | 微冒犯（microaggression）审计 |

## 实战案例：一个注册表单让 APAC 市场"感到自己不存在"

某 SaaS 产品计划进军日本与印尼市场，注册转化率在内测中远低于欧美。工程团队怀疑是加载速度，文化智能策略师的审计给出了另一个答案（代码还原节选）：

```typescript
// CQ 审计：检测 UI 数据中的文化摩擦
export function auditWorkflowForExclusion(uiComponent) {
  const auditReport = [];

  // 姓名字段检查
  if (uiComponent.requires('firstName') && uiComponent.requires('lastName')) {
    auditReport.push({
      severity: 'HIGH',
      issue: '僵硬的西方命名结构',
      fix: '合并为单一"全名/惯用名"字段。许多文化不存在'
         + '严格的姓/名二分：或用多个姓氏，或家族名在前。'
    });
  }

  // 色彩符号检查
  if (uiComponent.theme.errorColor === '#FF0000'
      && uiComponent.targetMarket.includes('APAC')) {
    auditReport.push({
      severity: 'MEDIUM',
      issue: '色彩符号冲突',
      fix: '中国金融语境中红色代表上涨。错误状态必须'
         + '用文字/图标显式标注，不能只靠红色传达。'
    });
  }
  return auditReport;
}
```

`firstName`/`lastName` 强制二分对日语姓名（姓在前）与印尼单名用户构成结构性排斥——不是翻译问题，是字段架构问题。修复方案是单字段"全名 + 惯用名"加后端弹性解析，而非本地化补丁。他的四阶段工作流在此完整走了一遍：盲区审计 → 针对性调研（日本与印尼的命名惯例）→ 给出结构性修正代码 → 解释"为什么原设计是排他的"让团队学到原则。内测反馈中最有力的一条来自印尼用户："这是第一个没让我觉得自己名字是错误的产品。"

## 实战案例：为图像生成注入反偏见约束

同一公司要生成一组"职场协作"主题的营销图像。直接生成的结果呈现系统性套路：亚裔角色总是工程师、年长者总是会议室背景板。策略师交付的负面提示词库（还原节选）：

```text
生成约束注入：
+ 所有角色以真实尊严呈现，衣着与姿态不套用种族模板
+ 亚洲面孔同时出现在决策者/发言者位置
- 禁止：minority 刻板职业分配
- 禁止：tokenism 式"角落里的多元化面孔"
- 禁止：夸张的肢体/表情套路化表演
```

配合生成结果的逐张审查（谁在说话、谁在做决定、谁在微笑服务），最终图像组通过了"权力位置分布"检查。他对这次交付的总结道破了 AI 内容的隐性风险：**模型偏见不会自己消失，它只会换一套更隐蔽的刻板印象出现；负面提示词不是可选项，是图像生成的卫生措施**。

## 使用技巧

- 在设计阶段介入而非发布前抢救：字段架构、色彩系统这类结构性问题，设计期改一行，发布后改一套。
- 给他目标市场的明确清单：审计深度取决于知道要为谁审。
- 生成图像默认带他的负面提示词库：反偏见应成为流水线标配而非专项检查。
- 接受他的"why"讲解：原则学会了，团队下次自己就能避坑。
