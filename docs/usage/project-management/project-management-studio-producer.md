# Studio Producer（工作室制作人）使用指南

> 🎬 **一句话定位**：在创意愿景与商业目标之间执秤的人——多项目组合管理、投资组合 ROI 平衡、高管级沟通，是工作室的"战略总指挥"。

## 这位 Agent 是谁

Studio Producer 是高管层的创意与技术项目组合操盘手。他的视角是"组合"而非"项目"：单个项目的好坏之上，还有整体投资配置、风险平衡、能力建设的问题。他的 Default requirement 是组合 ROI 25%+ 且 95% 按时交付——同时管住钱和准时，这是他与单项目经理的本质区别。

核心专长：

- 战略组合规划：项目分级（Tier 1 战略级 / Tier 2 增长级 / 创新管线）与预算分配
- 创意-商业对齐：让创意卓越服务市场定位，而非自我表达
- 高管与客户关系：董事会汇报、战略客户管理
- 团队与人才：高绩效团队组建与领导力培养
- 风险与创新平衡：组合层面的风险分散与突破性实验配额

## 什么时候雇佣他

| 场景 | 你能得到的产出 |
|------|--------------|
| 同时跑 N 个项目，资源永远不够分 | 战略组合规划（分层投资配置） |
| 创意团队与业务目标各走各的 | 创意愿景与商业目标的对齐框架 |
| 董事会要"看得懂的战略" | 执行官级组合评审报告 |
| 该押注创新还是守好现金流 | 风险平衡的组合投资策略 |
| 大客户关系需要高管级维护 | 战略客户管理方案 |

## 实战案例 1：项目组合的"重新配仓"

背景：一家 40 人的创意工作室同时跑 11 个项目，全年每个项目都说自己重要，年底盘点：8 个微利、2 个亏损、1 个爆款撑起全部利润，团队疲惫不堪。

你给他的输入：

```
11 个在跑项目，人力被摊薄，利润集中于 1 个爆款。
明年怎么排兵布阵？
```

他会给你的产出（要点还原）：

1. 组合诊断先分层：

```markdown
Tier 1（战略级，40% 资源）：爆款所在的品类深耕 + 2 个战略客户项目
Tier 2（增长级，40% 资源）：4 个健康现金流项目，维持但不扩张
创新管线（15% 资源）：3 个低成本实验（验证新品类）
止损区（5% 资源处理退出）：2 个亏损项目的有序收尾与客户关系保全
```

2. 每层的决策逻辑显式化：Tier 1 看战略卡位（市场前三目标），Tier 2 看现金流稳定性，创新管线看学习价值而非短期回报——"用不同的尺子量不同的项目"是组合管理的核心。
3. 团队配置跟着组合走：精锐力量集中 Tier 1，Tier 2 配成长期员工练兵，创新管线给想突破的人舞台。
4. 组合级 KPI：整体 ROI、按层达成率、人才保留率——单项目胜负之上看组合健康度。

**价值**：从"11 个项目都半死不活"到"结构清晰的进攻-防守-实验阵型"——资源不足的解法从来不是更努力，是重新配仓。

## 实战案例 2：创意方向与商业诉求的仲裁

背景：艺术总监想接一个获奖概率高但预算紧张的品牌重塑项目，销售 VP 认为该把产能留给利润率高的常规大客户。

雇佣他时可以这样提示：

```
艺术团队的机会项目 vs 销售团队的利润项目争夺同一批人力。
请给出仲裁框架与决策。
```

他会做的事：

1. 把争吵翻译成组合问题：这不是"谁对"，而是"声誉资产与现金流资产的配置比例"问题。
2. 量化两端：获奖项目对工作室的获客价值（历史数据：上次获奖后 6 个月内新客询价 +40%）vs 大客户项目的直接利润与人情维护价值。
3. 设计两全方案：项目错峰（获奖项目的设计前置期与大客户执行期错开）、人力混编（资深创意带新人参与机会项目，同时产能护住大客户）。
4. 仲裁原则透明化："本年度创新配额 15% 未用完，获奖项目入创新管线；但设置止损点——若超预算 20% 即降级为常规交付。"

**价值**：他让"创意 vs 商业"从立场之争变成资产配置问题——这类冲突在创意组织里永远存在，缺的从来是称重的秤。

## 使用技巧

- 给他全部项目的财务与人力数据（营收、利润率、占用人力），组合分析靠全景而非样本。
- 说清公司的战略意图（扩张/守成/转型），分层配比据此调整。
- 董事会汇报需求提前告知，他能在执行细节与战略叙事间自如切换颗粒度。
- 创新管线的"学习目标"要你参与定义——他要的是可度量的假设，不是情怀。
