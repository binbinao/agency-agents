# Studio Operations（工作室运营官）使用指南

> 🏭 **一句话定位**：让工作室这台机器顺滑运转的人——SOP 文档化、瓶颈消除、资源协调，95% 运营效率是他的默认目标。

## 这位 Agent 是谁

Studio Operations 是日常运营与流程优化专家，人设钩子是"Keeps the studio running smoothly — processes, tools, and people in sync"。他管理的对象是"流程、工具、资源"三者的同步：一项工作在团队之间流转时的每次卡顿、重复、返工，都是他的改进对象。他的方法论底色是持续改进（Kaizen 式）：度量 → 找瓶颈 → 优化 → 再度量。

核心专长：

- SOP 建设：带输入/动作/输出/质检四要素的分步流程文档
- 瓶颈消除：流程价值流分析与浪费识别
- 资源协调：设备、场地、工具的排期与利用率追踪
- 供应商管理：SLA 谈判与成本优化（年度成本目标 -10%）
- 运营报告：效率指标、响应时效、系统可用性的周期报告

## 什么时候雇佣他

| 场景 | 你能得到的产出 |
|------|--------------|
| 同一件事每个人做法都不一样 | SOP 文档 + 培训计划 |
| 团队总在"等某个资源"（设备/审批/权限）| 瓶颈分析与资源排期方案 |
| 供应商服务差价格高 | 供应商评估 + SLA 重谈方案 |
| 运营成本持续上涨 | 成本审计 + 优化路线图 |
| 新人上手要靠口口相传 | 岗位操作手册与知识库建设 |

## 实战案例 1：内容生产流水线的瓶颈手术

背景：一个内容工作室周产出从 20 篇降到 12 篇，团队加班却更慢，没人说得清卡在哪。

你给他的输入：

```
内容工作室：选题→初稿→设计配图→审核→发布 五个环节。
近两个月周产出 20 篇 → 12 篇。加班增加但产出反降。
请做瓶颈诊断与流程改造。
```

他会给你的产出（要点还原）：

1. 价值流度量先于开药方：每个环节的等待时间与处理时间分开统计——发现问题不在处理（各环节实际干活时间没变），而在等待：设计配图环节平均积压 3.5 天，因为全工作室只有一个设计师且没有排期规则。
2. 瓶颈手术：

```markdown
根因：设计环节无排期规则，紧急插入插队严重，普通稿平均等待 3.5 天
方案 1：配图需求分级（模板化封面走自助模板库，预估释放 40% 设计工时）
方案 2：设计需求进入周一集中排期，插队需运营负责人签字
预期：周产出恢复 18-20 篇，设计师加班时长 -50%
```

3. SOP 落地配培训：新排期规则写成带质检点的一页 SOP，全员 30 分钟培训，两周后复查采纳率。
4. 度量闭环：建立每周产能仪表盘（各环节等待/处理时长趋势），瓶颈复发可预警。

**价值**：产出恢复到 19 篇/周——注意他没加一个人、没买一个工具，只是让瓶颈显式化并给了它规则。

## 实战案例 2：供应商整合省钱

背景：工作室的图库、字体、云存储、协作工具分属 4 家供应商，年度总支出上涨 22%。

雇佣他时可以这样提示：

```
工具类年度支出 $48K，同比 +22%。分散采购，无人统一管理。
请做成本优化方案。
```

他会做的事：

1. 资产盘点：各工具的实际使用率（seat 利用率、下载量）——发现 30% 的付费席位是离职未回收的僵尸账号。
2. 供应商整合：图库与字体合并到一家综合创意订阅，云存储按实际用量降档。
3. SLA 重谈：以年度续约为筹码谈 15% 折扣，同时把响应时效写进 SLA（此前无 SLA，出问题没人管）。
4. 交付成本优化报告：目标执行路径 + 预期年度节省 $11K（-23%）+ 防复发机制（席位季度审计流程）。

**价值**：他的成本优化从不靠"砍服务降质量"——僵尸账号回收与整合议价这类"纯浪费清除"，才是可持续的省钱。

## 使用技巧

- 给他真实的时间与成本数据（哪怕粗糙），他的瓶颈诊断靠度量不靠感觉。
- 流程改造接受"先试点后推广"节奏，他默认带复查环节。
- 告诉他团队规模与增长率，SOP 的复杂度会匹配（小团队他不会上重型流程）。
- 运营指标想盯哪些（产出/时效/满意度）提前说，仪表盘按需配置。
