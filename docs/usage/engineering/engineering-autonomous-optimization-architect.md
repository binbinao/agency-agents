# Autonomous Optimization Architect（自主优化架构师）使用指南

> ⚡ **一句话定位**：自进化系统的"总督"——用影子流量持续 A/B 各家 LLM 与 API，赢了就自动换路由，但每个端点都套着熔断器与预算上限，"没有熔断器的自主路由只是一颗昂贵的炸弹"。

## 这位 Agent 是谁

Autonomous Optimization Architect 是自改进软件的治理者。他解决的是一个新问题：当你的系统依赖多个 AI/API 供应商时，谁来持续判断"哪个模型此刻性价比最高"并安全地切换？他的答案是一套自治机制：影子测试（5% 流量后台验证新模型）→ 数学化评分（禁止主观打分）→ 自动晋级（统计显著优于基线才切）→ 熔断兜底（成本/异常/攻击模式即时切断）。

他的核心人格是"财务上冷酷"：每个 LLM 架构提案必须附每百万 token 的成本估算（主路径 + 降级路径都要算）。

四条铁律：

- ❌ 禁止主观评分：影子测试前必须先定数学化的评分标准（如 JSON 格式对 5 分、延迟 3 分、幻觉 -10 分）
- ❌ 禁止干扰生产：所有实验流量异步走"影子通道"
- ✅ 必算成本：任何架构提案附完整成本估算
- ✅ 异常即停：流量暴增 500% 或连续 402/429 → 熔断、切降级、告警人类

## 什么时候雇佣他

| 场景 | 你能得到的产出 |
|------|--------------|
| LLM 账单月月暴涨 | 多供应商路由架构 + 成本护栏（单次执行成本上限） |
| 新模型发布想快速试水 | 影子测试框架（1 小时内对生产数据验证新模型） |
| 单一 API 供应商停服就全站瘫痪 | 多级降级路由 + 熔断器 |
| 想知道"便宜模型够不够用" | LLM-as-a-Judge 语义基准（针对你的具体任务测，不看通用榜单） |
| 爬虫/API 被恶意流量烧钱 | 攻击特征识别 + 熔断自动化 |

## 实战案例 1：把 LLM 成本砍掉 80% 而质量不掉

背景：一个文档抽取系统全量跑高端模型，月账单 $4,700，CTO 要求降本但不接受质量下降。

你给他的输入：

```
文档抽取任务（发票字段抽取）：当前 Claude Opus 全量，月 $4.7K。
听说 Gemini Flash 更便宜，但没人在我们的真实数据上验证过。
要求：降本 50%+，抽取质量不能降。
```

他会给你的产出（要点还原）：

1. 先立数学评分标准（他的铁律：主观打分出局）：

```markdown
评分卡（每份文档 0-100）：
字段完整抽取：每正确字段 +5
格式错误（JSON 解析失败）：-20
幻觉字段（出现发票上不存在的值）：-10
延迟 >5s：-3
```

2. 影子部署：5% 生产流量异步双跑——Gemini Flash 的输出用评分卡自动打分（LLM-as-a-Judge 由更便宜的老模型执行判卷），全程不影响线上。
3. 数据说话的晋级：1000 次影子执行后，"Flash 在此任务上达到 Opus 98% 质量但成本 1/10"→ 自动更新路由权重，全量切 Flash，Opus 降为疑难单兜底。
4. 护栏随行：单次执行成本上限 $0.05；Flash 连续 3 次超时 → 熔断切回 Opus → 管理员告警。

**价值**：月账单 $4.7K → $890（-81%），抽取质量统计不变——且这套机制此后自动运行，每有新模型发布 1 小时内完成影子验证。

## 实战案例 2：爬虫 API 被薅羊毛的熔断救援

背景：团队的网页抓取 API 配额一夜间被烧掉 $1,100，日志显示某 IP 段高频重试。

雇佣他时可以这样提示：

```
抓取 API 昨夜异常消耗 $1.1K，疑似恶意流量。
需要防再发的自动防护机制。
```

他会做的事：

1. 事后取证：遥测特征分析——请求频率 500% 暴增 + 连续 402（配额）响应，正是他的熔断签名（Halt on Anomaly 规则的靶子）。
2. 防护架构三件套：

```typescript
// 每个外部请求的强制三要素（他的 Default requirement）：
// 1. 严格超时（5s）
// 2. 重试上限（3 次）
// 3. 指定的更廉价降级路径（抓取 API 挂了 → 缓存优先 → 本地静态版）
// 熔断条件：成本超限 OR 失败速度异常 → 切断端点 + 告警人类
```

3. 无界重试禁令落地：审计现存代码里所有 `while true` 重试与无超时请求，全部加上限——"自主路由没有熔断器就是昂贵的炸弹"是他的原话逻辑。
4. 成本遥测面板：每次执行的成本记录入仪表盘，异常消耗 15 分钟内可见（不再是第二天看账单才知道）。

**价值**：同类攻击再来时，熔断在 $50 内触发切换（vs 上次 $1,100）——防护价值不在拦截攻击本身，在于损失被数学上限锁死。

## 使用技巧

- 使用前回答他的第一问："单次执行你愿意花的最大美元数是多少？"——预算上限是他一切设计的锚点。
- 每个昂贵 API 都给他指一个最便宜的可用替代，降级路径不能空白。
- 新模型影子测试的评分标准需要你参与定义（业务上什么算"好输出"）。
- 他与其他 agent 的分工：应用安全找 Security Engineer，服务器健康找 Infrastructure Maintainer——他只管"第三方 AI/API 的动态经济学"。
