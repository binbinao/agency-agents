# Inclusive Visuals Specialist（包容性视觉专家）使用指南

> 🌈 **一句话定位**：对抗 AI 底层模型系统性偏见的提示词专家——让生成图像里的多元人群有尊严、有真实感，而不是刻板印象拼贴。

## 这位 Agent 是谁

Inclusive Visuals Specialist 是专注"真实人类呈现"的提示词工程师。他的战场是 Midjourney、Sora、Runway、DALL-E 这些基础模型的系统性缺陷：克隆脸（多元人群生成成同一张脸）、"异域化"打光、乱码文化符号、地理错误的建筑。他的人设宣言是：身份不是提示词里的一个描述词，而是需要专业技术才能准确呈现的领域。

他的四条铁律：

- ❌ 禁止"克隆脸"：多元群像必须强制指定不同的面部结构、年龄、体型
- ❌ 禁止乱码文字/符号：非英文文字和文化符号必须负面提示词排除
- ❌ 禁止"英雄符号"构图：人的瞬间是主体，不是悬浮的完美文化符号
- ✅ 强制物理真实：视频中头巾的垂坠、轮椅轮子与地面的接触，必须显式定义物理行为

## 什么时候雇佣他

| 场景 | 你能得到的产出 |
|------|--------------|
| 营销素材需要多元人群形象 | 带反偏见约束的提示词架构（主体/行动/情境/镜头/排除项分层） |
| 生成多元群像总出现"同一张脸" | 面部/年龄/体型差异化强制约束 + 负面提示词库 |
| 涉及特定文化的视觉（节日/地域） | 文化准确性锚定：真实建筑、正确着装、适合肤色的打光 |
| AI 视频中的残障辅具渲染出错 | 移动辅具（轮椅/义肢/拐杖）的物理一致性提示词 |
| 企业需要"伦理 AI 图像"规范 | 企业级 Ethical AI Imagery 品牌指南 |

## 实战案例 1：开斋节营销视觉的正确打开方式

背景：品牌要做开斋节campaign，直接生图的结果是：完美得可疑的巨型新月占据画面、人物脸谱化、背景文字乱码。

你给他的输入：

```
我们要做开斋节祝福视觉，面向东南亚市场。
之前直接生成的图被内部审查打回：符号悬浮、人物假、文字乱码。
```

他会给你的产出（要点还原）：

1. 先点名问题根源（他的风格就是直说）："当前提示词大概率触发了模型的'异域化'偏见，我注入技术约束确保光线与地理建筑反映真实生活。"
2. 主体层：马来裔家庭，三代同堂，各自明确年龄与体态，自然的节日着装——不是所有女性都戴头巾，也不是没有任何人戴。
3. 情境层：吉隆坡排屋区的真实建筑语汇，开斋节灯饰是家居尺度的彩链，不是悬浮的巨型宗教符号。
4. 镜头层：为深肤色优化的柔和中侧光，"保留肤色 richness 且不过曝高光"。
5. 排除层：负面提示词显式排除乱码文字、克隆脸、超饱和塑料光、科幻元素。

**价值**：过审率从"碰运气"变成结构性保证——被呈现的社群成员看到图，能认出"这是我们的真实生活"，这正是他的成功指标（社群验证）。

## 实战案例 2：让轮椅在 AI 视频里不穿帮

背景：无障碍宣传视频用 Runway 生成，轮椅轮子穿进地面、人物转身时轮椅凭空变形成普通椅子。

雇佣他时可以这样提示：

```
Sora/Runway 生成残障用户使用产品的视频，
轮椅渲染频繁穿模。请提供物理一致性约束方案。
```

他会做的事：

1. 在提示词中显式定义运动物理："轮椅轮子全程与路面保持接触；转向时左轮角速度低于右轮；扶手推动的姿态与椅背角度一致。"
2. 织物物理同样定义：外套下摆随推行自然摆动，不与轮辐穿模。
3. 交付 7 点 QA 清单，生成后人工核对：辅具物理、面部多样性、符号真实性、打光合理性等——他不信任"生成就等于合格"。
4. 若角色还要跨模型使用（Midjourney 生成 → Runway 动画），他提供多模态连续性提示词，保证角色文化特征在两个模型间不漂移。

**价值**：AI 视频最容易翻车的不是美观而是物理穿帮，尤其涉及辅具时会被残障社群一眼识破——他的约束体系让"包容"不再是公关辞令而是可验证的技术规格。

## 使用技巧

- 别只说"要多元"，说出具体的人群、地域、文化语境，他的文化锚定才有落点。
- 他默认会拒绝"Kumbaya 式拼贴"（各族人脸凑一张图假笑），如果你真的需要群像，接受他给出的差异化约束方案。
- 生成结果务必走他的 QA 清单再发布，他自己也把这作为流程的一部分（Phase 4 审查门）。
- 他对企业级客户有额外产出：一套可复用的"伦理 AI 图像生成"品牌规范。
