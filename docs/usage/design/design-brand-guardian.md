# Brand Guardian（品牌守护者）使用指南

> 🎨 **一句话定位**：品牌的"最凶保护者与最热倡导者"——从品牌战略到视觉系统到商标保护，一条龙守护品牌一致性。

## 这位 Agent 是谁

Brand Guardian 是品牌战略与品牌资产管理专家。他的世界观很朴素：品牌靠一致性成功，靠碎片化失败。他桥接商业战略与品牌执行，交付的不是"一个 logo"，而是整套能自我执行的品牌系统。

核心专长：

- 品牌地基：Purpose/Vision/Mission/Values/Personality/Promise 六件套
- 视觉识别系统：logo 变体、色彩（含 WCAG 无障碍组合）、字体层级、CSS 变量化的设计规范
- 品牌语音与信息架构：slogan、价值主张、分层 key messages
- 品牌保护：商标注册策略、合规监控、危机公关

## 什么时候雇佣他

| 场景 | 你能得到的产出 |
|------|--------------|
| 新品牌从零起步 | 完整品牌地基文档 + 视觉识别系统 + 品牌指南 |
| 各渠道品牌表达混乱 | 品牌合规审计 + 纠偏指导 |
| 品牌要升级或重塑 | 基于市场的品牌演进策略（何时该变、何时该守） |
| 担心品牌被滥用/侵权 | 商标保护策略 + 监控机制 |
| 品牌进入新市场/新文化 | 文化敏感性审查与本地化适配 |

## 实战案例 1：给 SaaS 初创搭品牌地基

背景：一家 B2B SaaS 初创做完产品，发现官网、销售 PPT、产品界面三种风格，客户记不住他们是谁。

你给他的输入：

```
我们是面向中小商家的订阅管理 SaaS「星舟」。
目前没有成文的品牌体系，各渠道表达混乱。
请帮我们建立品牌地基与视觉系统。
```

他会给你的产出（要点还原）：

1. 先补地基再谈视觉（他的 Brand-First 规则）：

```markdown
## Brand Purpose
让中小商家用得起、玩得转大公司级的订阅运营能力

## Brand Personality
- 靠谱：承诺的上线时间从不跳票
- 亲和：说人话，不堆术语
- 进取：主动替商家想下一步
```

2. 视觉系统直接给到 CSS 变量级，开发可以即插即用：

```css
:root {
  --brand-primary: #2E5AAC;      /* 主色 */
  --brand-secondary: #F5A623;    /* 辅色 */
  --brand-neutral-100: #F8F9FA;  /* 最浅中性 */
  --brand-neutral-900: #212529;  /* 最深中性 */
  --brand-space-md: 1rem;        /* 4px 倍数间距系统 */
}
```

3. logo 三变体（横版/竖版/图标）带最小尺寸与净空规范。
4. 附赠（他的 Default requirement）：商标注册类别建议与品牌合规监控流程——这是其他"品牌设计师"不会主动给你的。

**价值**：他交付的是"团队离开他也能自我执行"的品牌系统：任何设计师拿到这套 CSS 变量 + 指南，产出的物料都是同一个星舟。

## 实战案例 2：品牌危机中的守门

背景：公司一则广告被质疑文化冒犯，社媒开始发酵。

雇佣他时可以这样提示：

```
我们的节日广告在社交媒体被指文化不敏感，正在发酵。
请提供品牌危机应对方案。
```

他会做的事：

1. 先评估事实：广告内容、指控性质、传播范围，判断是误解还是真失误。
2. 给出分级应对：若属误解，走澄清 + 沟通策略；若属真失误，坦诚道歉 + 下架 + 内部审查，绝不狡辩。
3. 把这次事件沉淀为品牌指南里的新条款（文化敏感性清单），防止重演。
4. 危机后品牌健康度跟踪方案。

**价值**：把"公关直觉"变成"有方法论的品牌保护流程"，且确保组织从危机中学到东西。

## 使用技巧

- 他坚持"战略先行"：跳过地基直接要 logo，会被他先用三个问题打回来。
- 色彩方案要告诉他目标市场，他会主动做 WCAG 无障碍组合检查。
- 视觉系统交付格式是 CSS 变量，直接进前端项目的 design token 体系。
- 商标保护部分在早期公司容易被忽略，但这是他的 Default requirement，建议保留。

## 与其他 Agent 的接力

- 品牌地基完成后，视觉执行交给 **UI Designer**（`design-ui-designer.md`）落地为产品界面设计系统。
- 品牌信息架构交给 **Visual Storyteller**（`design-visual-storyteller.md`）转化为品牌叙事内容。
- AI 生成品牌图像时，请 **Image Prompt Engineer**（`design-image-prompt-engineer.md`）按品牌色彩与调性写提示词。
- 跨部门视角，见[跨部门工程故事：一个功能从想法到上线](../story-cross-team-feature.md)。
