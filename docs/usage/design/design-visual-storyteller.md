# Visual Storyteller（视觉叙事者）使用指南

> 🎬 **一句话定位**：把复杂信息变成打动人的视觉故事——每个视觉叙事都有完整的故事弧（开端/冲突/结局），跨平台适配是标配。

## 这位 Agent 是谁

Visual Storyteller 是视觉传达与叙事设计专家。他的方法论核心是"故事弧"：开端（铺垫）→ 中段（冲突）→ 结局（解法），主角往往是客户/用户，冲突是他们的痛点，解法是你的产品。他处理的不是"做几张好看的图"，而是"让信息被记住、被感受到"。

核心专长：

- 视觉叙事开发：故事弧、情绪旅程映射、视觉节奏控制
- 多媒体设计：视频/动画/动效/信息图/数据可视化
- 跨平台适配：Instagram Stories（竖屏+互动）、YouTube（横屏+封面优化）、TikTok（短视频+趋势）、LinkedIn（专业向信息图）、Pinterest（竖版+季节性）
- 渐进式披露：复杂信息分层揭示，保证可理解性

## 什么时候雇佣他

| 场景 | 你能得到的产出 |
|------|--------------|
| 产品故事讲不出感染力 | 完整故事弧设计（用户为主角、痛点为冲突）+ 分镜 |
| 数据报告没人看 | 信息图/数据可视化叙事化改造 |
| 一套内容要发多个平台 | 各平台格式与节奏适配的跨平台视觉策略 |
| 品牌需要情感连接 | 情绪旅程映射（情绪峰值与低谷的节奏设计） |
| 复杂概念需要 30 秒讲清 | 动画/动效分镜与节奏方案 |

## 实战案例 1：把枯燥的数据报告变成传播故事

背景：一家物流公司年度客户报告全是表格，客户不看，销售也没法用它讲故事。

你给他的输入：

```
我们有年度配送数据：平均时效缩短 18%、破损率下降 40%、
覆盖城市新增 30 个。现在的报告是 40 页 PDF 表格，没人看完过。
请把它变成客户愿意看完并转发的视觉故事。
```

他会给你的产出（要点还原）：

1. 先搭故事弧，而不是先画图：

```markdown
开端：凌晨 4 点，你的货还在 800 公里外（制造代入感的冲突）
中段：这一年，我们重做了什么（3 个转折点对应 3 个数据）
结局：现在，货在你客户的门口（用具体场景收束数据）
```

2. 每个数据点配视觉隐喻：18% 时效提升 → 两座城市间的距离被"折叠"的动画；40% 破损率下降 → 从"易碎品小心翼翼"到"放心托付"的画面对比。
3. 渐进式披露：总览信息图扫一眼可得结论，感兴趣的下钻看细节——不是把 40 页压成 4 页，而是分层。
4. 跨平台拆解：LinkedIn 发静态信息图三连，YouTube 发 90 秒动画版，销售拿到的是可放映的 10 页叙事版。

**价值**：同样的数据，从"归档文件"变成"销售武器与传播素材"——他的成功指标就是视觉内容互动率 +50%、故事完读率 80%。

## 实战案例 2：新产品发布的跨平台视觉叙事

背景：SaaS 产品发布新版本，需要一套贯穿官网、社媒、发布会的视觉叙事。

雇佣他时可以这样提示：

```
新版本核心卖点：把原来 6 步的配置流程压缩到 1 步。
需要官网 hero、社媒系列、发布会开场视频的视觉叙事方案。
```

他会做的事：

1. 情绪旅程映射：目标情绪曲线是"共鸣（我也被 6 步折磨过）→ 释放（原来可以 1 步）→ 期待（还能更简单吗）"，所有物料围绕这条曲线设计。
2. 主角永远是用户：官网 hero 不放产品截图，放用户的"6 步 → 1 步"前后对比场景；产品只作为解法在中后段登场。
3. 视觉节奏：发布会开场视频前 15 秒全是用户痛点蒙太奇（共鸣铺垫），第 16 秒才出现产品——节奏服务于情绪，不服务于功能罗列。
4. 无障碍与文化敏感性检查随交付：字幕、对比度、避免特定文化中的负面手势符号。

**价值**：发布物料从"功能清单播报"变成"有情绪起伏的叙事"，这是转化率与记忆度的差别。

## 使用技巧

- 给他品牌指南与受众研究（他的人设会主动读取这些），叙事基调会向品牌人格收敛。
- 说出投放平台清单，跨平台适配是他交付的一部分，别自己再二次加工。
- 复杂信息别自己先简化，他的渐进式披露设计比"砍内容"高明。
- 期望首轮概念就有较高完成度：他的目标是 95% 首轮通过率，反馈尽量具体（哪个情绪点不对），他迭代很快。
