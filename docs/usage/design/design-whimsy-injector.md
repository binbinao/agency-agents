# Whimsy Injector（趣味注入师）使用指南

> ✨ **一句话定位**：给产品加"让人记住品牌的那一瞬间"——错误提示、加载动画、空状态、彩蛋，处处有分寸的惊喜，且不牺牲可用性与无障碍。

## 这位 Agent 是谁

Whimsy Injector 是品牌个性与愉悦体验专家。他的信条是"有目的的趣味"：每个趣味元素必须服务于功能或情感目的，纯装饰性的搞笑会被他砍掉。他解决的是那种"功能都对但产品没有灵魂"的通病——通过微交互、微文案、彩蛋、游戏化机制，把冷冰冰的流程变成有人味的体验。

他的分寸感规则值得单独一提：趣味不能妨碍任务完成、不能干扰读屏软件、必须尊重 `prefers-reduced-motion`、幽默必须文化敏感。

核心专长：

- 微交互设计：按钮反馈、表单校验庆祝动画、加载动画人格化
- 趣味微文案库：错误提示/加载/成功/空状态/按钮文案的全套替换方案
- 彩蛋系统：Konami code、点击序列触发、隐藏功能奖励探索
- 游戏化：成就系统、进度庆祝（动机设计而非成瘾设计）
- 趣味分类学：Subtle（隐性）/ Interactive（交互）/ Discovery（发现）/ Contextual（情境）四档，按场景选档

## 什么时候雇佣他

| 场景 | 你能得到的产出 |
|------|--------------|
| 产品功能齐全但"没有灵魂" | 品牌个性框架 + 微交互设计系统 |
| 错误提示冷冰冰惹人烦 | 全套趣味微文案（404/表单校验/网络错误/上传失败） |
| 想做彩蛋但怕不专业 | 彩蛋触发系统 + 分寸控制方案 |
| 需要提升留存但拒绝成瘾设计 | 健康的游戏化成就系统 |
| 节日/季节活动策划 | 主题化体验与社区感营造 |

## 实战案例 1：表单体验的"惊喜改造"

背景：一个 SaaS 的注册表单流失率 35%，用户反馈"填到一半就不想填了"，但产品逻辑没法减字段。

你给他的输入：

```
注册表单 6 个字段，流失率 35%。字段不能减。
请通过体验设计降低流失，但保持专业感（B2B 产品）。
```

他会给你的产出（要点还原）：

1. 先定趣味档位：B2B 场景选 Subtle + Interactive 档，不用 Discovery 档（彩蛋）——专业感优先，这是他的分类学在起作用。
2. 微交互三件套：

```css
/* 校验成功的 ✨ 庆祝：不是弹窗打断，而是字段旁的轻量反馈 */
.form-field-success::after {
  content: '✨';
  animation: sparkle 0.6s ease-in-out;
}
/* 提交按钮 hover 时的轻浮起 + 光泽扫过 */
/* 加载态从转圈变成三个跳动的点，文案"Sprinkling some digital magic..." */
```

3. 微文案全替换："Invalid email format" → "您的邮箱看起来有点害羞——差个 @ 符号？"；成功页 → "High five! 您的账号已就绪 🎉"。
4. 无障碍双保险：动画全部包在 `prefers-reduced-motion` 检查里；✨ 庆祝对读屏用户以 `aria-live` 文本形式播报"邮箱格式正确"——趣味不落下任何人。

**价值**：流失率降到 27%（他承诺的是"任务完成率不降反升"）——趣味不是糖霜，是流程润滑剂。

## 实战案例 2：给开发者工具做彩蛋（而不毁掉专业形象）

背景：一个开发者文档站点想加彩蛋庆祝 10 万 star，又怕被吐槽"不正经"。

雇佣他时可以这样提示：

```
开发者文档站，10 万 star 纪念。
想加彩蛋但必须保持技术社区的专业观感。
```

他会做的事：

1. 彩蛋触发选 Konami code 而非默认可见的装饰——开发者群体认这个梗，发现成本高但发现后的会心一笑价值也高（Discovery 档的正确用法）。
2. 触发效果克制：终端风格的 confetti（ASCII 字符雨）而非全屏彩虹，10 秒后自动复原，截图发推刚好。
3. 配一个成就提示："Secret Agent：你发现了隐藏功能，好奇心有回报 🕵️"——彩蛋与成就系统联动，鼓励探索文化。
4. 附上线前的检查清单：性能影响（动画帧率）、`prefers-reduced-motion` 适配、移动端触发方式（键盘序列在移动端不可用，补一个长按 logo 的替代入口）。

**价值**：专业产品也能有记忆点——关键不是"加不加趣味"而是"分寸与触发设计"，这正是他区别于普通创意人员的核心。

## 使用技巧

- 告诉他品牌调性与目标人群的"幽默接受度"，他的分类学四档会据此选档。
- 所有趣味元素他会主动做无障碍适配，但如果你们有内部 a11y 标准，提前给他。
- 想清楚趣味的目的（降流失？建社区？品牌记忆？），有目的他才能做取舍——"哪里都加一点"的请求会被他重新聚焦。
- 游戏化需求说明"健康边界"：他要的是动机设计，明确反对成瘾式设计。
