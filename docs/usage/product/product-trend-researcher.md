# Trend Researcher（趋势研究员）使用指南

> 🔭 **一句话定位**：在趋势进入主流前 3-6 个月发现它——弱信号检测、多源三角验证、带置信区间的预测，是产品战略的眼睛。

## 这位 Agent 是谁

Trend Researcher 是市场情报与趋势分析专家，人设钩子是"Spots emerging trends before they hit the mainstream"。他的方法论有鲜明的量化特征：50+ 信源自动聚合、统计验证的弱信号检测、采用曲线建模（创新者→早期采用者→早期大众）、每份报告 15+ 独立信源交叉验证。

核心专长：

- 趋势识别：弱信号检测（主流化前 3-6 个月提前量）、生命周期阶段判断（萌芽/成长/成熟/衰退）
- 数据源覆盖：搜索量分析、社媒指标、专利申请、投资流向、监管动态
- 竞争情报：直接/间接/新兴对手三层分析 + SWOT + 白空间地图
- 市场量化：TAM/SAM/SOM 三层测算（±20% 置信区间）
- 情景规划：多假设概率加权的未来推演

## 什么时候雇佣他

| 场景 | 你能得到的产出 |
|------|--------------|
| 新市场进入前的机会评估 | TAM/SAM/SOM 测算 + 进入策略与时机建议 |
| 产品路线图需要前瞻输入 | 趋势简报（2 页高管摘要）+ 时间线预测 |
| 竞品动作看不懂意图 | 竞争格局地图 + 定位白空间分析 |
| 担心被跨界颠覆 | 颠覆风险评估 + 情景规划与应对预案 |
| 投资方向需要论据 | 技术成熟度分析 + 投资流向情报 |

## 实战案例 1：判定"AI 客服"是真趋势还是泡沫

背景：一家 SaaS 公司董事会要求评估"是否全面押注 AI 客服赛道"，CMO 觉得是风口，CTO 觉得是炒作。

你给他的输入：

```
董事会要决定是否将 40% 研发资源投入 AI 客服方向，3 年周期。
请提供该趋势的成熟度评估与进入时机建议。
```

他会给你的产出（要点还原）：

1. 信号强度分层评估（他的招牌方法论）：

```markdown
强信号：企业级采用率连续 4 季度增长；头部厂商营收结构中
  AI 客服占比从 8% → 23%；相关专利申请年增 65%
中信号：VC 投资流向集中但轮次前移（估值泡沫风险）
弱信号：传统客服外包行业的论坛出现"转型焦虑"讨论
  （下游需求侧的真实压力指标）
```

2. 采用曲线定位：当前处于"早期采用者→早期大众"过渡带，窗口期 12-18 个月——晚于此进入将面对已固化的头部。
3. 竞争白空间：通用客服已红海，但垂直行业（医疗/法务合规场景）的玩家缺位，且监管壁垒构成天然护城河。
4. 情景规划三分支：乐观（AI 采用加速，概率 40%）/ 基准（平稳渗透，45%）/ 悲观（监管收紧+幻觉事故引发信任危机，15%），各附应对策略。
5. 结论带置信区间："建议进入，但以垂直场景切入而非通用赛道；40% 资源投入在基准情景下 3 年 ROI 为正的概率约 70%。"——注意他给的是概率与条件，不是拍胸脯的保证。

**价值**：董事会决策从"CMO vs CTO 的直觉对轰"变成"概率加权的情景选择"。

## 实战案例 2：为产品路线图做趋势雷达

背景：产品团队每年做路线图都靠"去年做了什么今年接着做什么"，被 CEO 批评没有前瞻性。

雇佣他时可以这样提示：

```
我们需要一套持续的趋势监测机制，为季度路线图评审提供输入。
预算有限，优先覆盖与订阅管理 SaaS 相关的领域。
```

他会做的事：

1. 搭建监测体系：50+ 信源中筛出与你相关的 15 个（行业媒体、专利库、融资数据库、开发者社区），设置关键词告警。
2. 周度简报：新信号按趋势评分排序，只报增量不炒冷饭。
3. 季度深潜：把累积信号做成生命周期地图——哪个趋势从萌芽进了成长期（该动手了）、哪个该收割了。
4. 预测准确性回溯：每季度对照上期预测与实际，误差分析与方法论修正——他连自己都要做 QA。

**价值**：前瞻性从"一年一次的 brainstorm"变成"持续运转的雷达"，路线图评审第一次有了外部时间的坐标系。

## 使用技巧

- 明确决策场景（进不进/投不投/做不做），他的分析会收敛到该决策需要的信息，不撒胡椒面。
- 对"紧急请求"付加急：48 小时交付优先级排序的快速评估。
- 他的每份报告带信源可信度评分，引用结论时注意区分强/弱信源支撑。
- 预测是概率不是承诺，配合他的季度回溯机制使用效果最佳。

## 与其他 Agent 的接力

- 趋势洞察输入给 **Product Manager**（`product-product-manager.md`）做机会评估，输入给 **Trend Researcher 的结论** 也服务于路线图评审（配合 Sprint Prioritizer）。
- 营销侧的趋势利用（平台风向、算法变化）与 `marketing/` 目录的平台策略师协作。
