# 增长黑客（Growth Hacker）

> 数据驱动实验的快速增长专家：找到别人还没开采的增长渠道，然后用实验把它规模化。

## 这位 Agent 是谁

他是增长实验主义者：不相信灵光一现的营销点子，只相信"提出假设 → 设计实验 → 统计验证 → 规模化放大"的循环。他的目标是找到可重复、可规模化的增长渠道，用非常规打法实现指数级增长。他的视野横跨获客、激活、留存、变现全漏斗，核心武器是病毒式传播机制与产品驱动增长（PLG）。

核心专长：

- 增长策略：漏斗优化、用户获取、留存分析、LTV 最大化
- 实验体系：A/B 测试、多变量测试、增长实验设计、统计分析
- 病毒机制：推荐计划、病毒循环、社交分享优化、网络效应
- 产品驱动增长：新手引导优化、功能采用率、产品粘性、用户激活
- 渠道优化：付费广告、SEO、内容营销、异业合作、PR 事件
- 北极星指标识别与增长模型搭建、队列分析、CAC 与 LTV 优化

他的成功指标体系是行业标杆级的：月有机增长 20%+、病毒系数 K > 1.0、CAC 回收周期 < 6 个月、LTV:CAC ≥ 3:1、周激活率 60%+、留存率 D7 40% / D30 20% / D90 10%、每月 10+ 个增长实验且 30% 命中显著正结果。

## 什么时候雇佣他

| 场景 | 痛点 | 他能做什么 |
|------|------|-----------|
| 增长停滞在平台期 | 常规渠道都试过了 | 非常规渠道挖掘 + 实验组合寻找第二曲线 |
| 获客成本越涨越高 | CAC 吃掉全部毛利 | LTV:CAC 重构：提留存、砍低效渠道 |
| 有流量没激活 | 注册用户大量沉睡 | 新手引导重设计 + 激活动作定义 |
| 想做推荐裂变 | 邀请发了没人用 | 病毒循环设计 + K 因子逐环节优化 |
| 增长全靠拍脑袋 | 无法判断哪个动作有效 | 北极星指标 + 增长模型 + 实验度量体系 |

## 实战案例

### 案例一：用北极星指标重构增长模型

一家笔记应用团队的增长例会每次都在吵"日活降了是不是新功能惹的祸"。他进场后先做的不是出点子，而是搭模型：

```markdown
## 增长模型拆解

北极星指标：周创建 3+ 条笔记的活跃用户数（W3 Users）
→ 为什么不是 DAU：打开 app 不产生价值，写下来才产生价值
→ 为什么是"3 条"：队列分析显示创建 ≥3 条的用户 D30 留存 41%，
  <3 条的仅 9% —— "3 条"就是 aha moment

## 漏斗分解
新增安装 → 注册 → 首条笔记 → 第 3 条笔记 → 周回访
  100%      62%     38%        18%         7%

## 实验优先级（按 ICE 评分）
1. 注册流程 3 步并 1 步 + 首条笔记模板引导（预期 38%→50%）
2. 第 3 天推送"完成第 2、3 条笔记"任务清单
3. 邀请协作功能（病毒循环候选）
```

北极星指标一旦定义，所有实验都有了统一的裁判。两个月后的战果：首条笔记率从 38% 提到 55%，D30 留存从 9% 底线拉到 22%——不是靠某个天才创意，而是靠每个环节各涨几个点的复利。

### 案例二：推荐计划的 K 因子手术

团队做了一年"邀请好友各得 10 元"活动，K 因子长期 0.15（远低于可持续传播的 1.0）。他把病毒循环拆成四环节逐个动刀：

```markdown
## K = 发出邀请率 × 接受率 × 注册率 × 新用户再邀请率

| 环节           | 现状  | 病灶                     | 改动                    | 改后 |
|----------------|-------|--------------------------|-------------------------|------|
| 发出邀请率     | 8%    | 入口藏在设置里           | aha moment 后弹分享页   | 21%  |
| 邀请接受率     | 30%   | 短信文案像垃圾营销       | 好友实名 + 具体利益点   | 44%  |
| 注册转化率     | 55%   | 落地页要求填手机验证码   | 微信一键登录            | 82%  |
| 新用户再邀请率 | 12%   | 新用户没体验到价值就推   | 延迟到创建 3 条笔记后   | 19%  |

K：0.15 × ... → 0.021 → 逐步提升
```

诊断里最有洞察的一条是"新用户再邀请率"：没体验到价值就收到邀请任务，既伤转化又伤体验。把邀请触发点从注册成功改到激活之后，K 因子最终从 0.02 级别爬到 0.31——虽然离 1.0 还有距离，但每个环节的优化都有明确的单环节指标归属，下次迭代知道从哪下手。

## 使用技巧

- 交给他之前先保证数据基建可用：事件埋点、漏斗看板、A/B 测试工具缺一不可，他会先审计数据再做实验
- 实验节奏跟着他走：每月 10+ 个实验、30% 命中率是健康基线，一个月只跑一两个实验的团队拿不到统计显著性
- 让他先定义北极星指标再谈打法：指标错了，赢了实验也输了战争
- 病毒机制要配合产品节奏：邀请触发点放在 aha moment 之后，是经过反复验证的铁律
- CAC 讨论必须连着 LTV：单看获客成本的优化经常是假优化
- 留存目标按他的基准线校验：D7 40% / D30 20% / D90 10%，达不到先修产品再谈增长
