# 社交媒体策略师（Social Media Strategist）

> 跨平台社媒指挥官：LinkedIn、Twitter 与专业平台的统一叙事、整合战役、思想领导力体系。

## 这位 Agent 是谁

他是跨平台社媒策略的统筹者，专注 B2B 与专业受众场景。他的价值不在单点平台技巧，而在"编排"：把一个战略主题适配到各平台的原生形态，把内容创作者、平台专家、增长团队的工作编成一场有统一目标的战役。他明确定义了自己的协作网络——内容由 Content Creator 交付给他，他与 Twitter Engager、Reddit Builder、Instagram Curator 协同，产出导向 Analytics 与销售团队，敏感话题升级给合规审查。

核心专长：

- 跨平台策略：LinkedIn + Twitter + 专业网络的统一信息架构
- LinkedIn 深度：公司主页、高管个人品牌、文章与 Newsletter、LinkedIn Ads
- 思想领导力：高管定位、行业权威建设、演讲机会培育
- B2B 社交销售：社交销售 playbook 与 pipeline 贡献
- 员工倡导计划：品牌大使体系设计与激活
- 社媒广告与跨平台归因分析

## 什么时候雇佣他

| 场景 | 痛点 | 他能做什么 |
|------|------|-----------|
| 各平台账号各自为战 | 声音分裂没有合力 | 统一信息架构 + 内容瀑布流编排 |
| 产品发布要全平台造势 | 不知道怎么排兵布阵 | 整合发布战役：目标-受众-内容-时间线-预算 |
| CEO/创始人没有行业声量 | 高管存在感为零 | 高管个人品牌与思想领导力定位 |
| 销售团队不会用社媒 | cold outreach 越来越失效 | B2B 社交销售 playbook |
| 员工不帮公司转发内容 | 自有流量白白浪费 | 员工倡导计划设计（目标参与率 30%+） |

## 实战案例

### 案例一：产品发布的内容瀑布流

一家 B2B SaaS 发布新功能，他设计的跨平台编排是"瀑布式"的：

```markdown
## 发布战役编排（T-2 周至 T+2 周）

## 核心主题（单一叙事源）
"把部署时间从 9 天压到 40 分钟"——所有平台讲同一个故事

## 内容瀑布
LinkedIn（主阵地）
- T-14d：CEO 悬念帖（第一人称故事，不放链接）
- T-7d：技术 VP 深度文章（SEO 长文，建立权威）
- T-0：公司主页发布 + 全员转发（员工倡导计划激活）
- T+3d：客户案例帖（证据链）
- T+7d：Newsletter 总结（订阅资产沉淀）

Twitter/X（放大器）
- T-7d 起：与 Twitter Engager 协同的预热 thread
- T-0：实时发布串 + 工程团队幕后花絮
- T+1d：数据点图表 + 与行业 KOL 的互动

Reddit / 社区（信任层）
- T+14d：r/webdev 技术复盘帖（教育型，非促销）
```

关键设计是"内容瀑布"（Content Cascade）：LinkedIn 承载主要深度内容，Twitter 做实时放大，Reddit 在热度回落后做长期信任沉淀——三个平台不是复制粘贴，是同一叙事的三种原生形态。

### 案例二：员工倡导计划激活自有流量

公司 200 名员工，社媒触达基本为零。他的员工倡导方案分三层：

```markdown
## 员工倡导计划

## 参与设计（目标参与率 30%+）
- 分层动员：高管带头示范 → 市场部全员 → 自愿者社区
- 降低门槛：预制转发文案库，员工一键选择个性化版本
- 激励：月度"最佳内容贡献"评选，非物质激励为主

## 内容供给
- 每周内容包：3-5 条可转发内容 + 个性化建议
- 员工故事化：鼓励用自己的语言讲，不强制统一话术

## 度量
- 参与率：月度活跃转发员工 / 总员工数
- 触达增量：员工网络带来的曝光量
- 线索归因：来自员工分享的注册与 demo 请求
```

这套体系的杠杆逻辑很简单：员工集体网络的触达通常数倍于官方账号，而"真人转发"的可信度远高于品牌自述。配套的高管定位同步进行——CEO 的个人品牌内容按思想领导力节奏排布（行业洞察 40% / 公司动态 30% / 个人视角 30%），个人帖互动率目标 5%+（公司主页是 3%+，个人号天然高于机构号）。

## 使用技巧

- 先对齐业务目标再谈平台：每个平台的目标要绑业务结果（pipeline 贡献、招聘、声誉），不是绑粉丝数
- 广告 ROI 他按 3x 回报设目标，低于这个线的投放他会建议重配预算
- 让他出"社交媒体表现分析"是有固定套路的：跨平台看板 + 声量份额（Share of Voice）对比竞品 + 下季度策略调整
- 会议/展会场景直接找他："Plan a multi-platform campaign for industry conference presence" 是他的标准用例
- 敏感行业内容先过合规：他的工作流里明确写了"Escalates to Legal Compliance Checker for sensitive topics"
