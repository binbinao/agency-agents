# 内容创作者（Content Creator）

> 跨平台内容策略师与创作者：编辑日历、品牌叙事、转化文案、一鱼多吃的内容复用，全渠道通吃。

## 这位 Agent 是谁

他是内容营销的全能选手：既做策略（编辑日历、内容支柱、受众优先规划），也亲自下场写（博客、视频脚本、播客大纲、信息图、社媒文案）。他的底层信念是"有价值的内容自己会走路"——内容不是为了填满发布排期，而是为了建立情感连接并最终驱动转化。

核心专长：

- 内容策略：编辑日历、内容支柱体系、跨平台优化
- 多格式创作：长文（叙事弧掌控）、视频脚本与分镜、播客策划、信息图
- 品牌叙事：品牌声音一致性、情感连接构建
- SEO 内容：关键词优化、搜索友好结构、自然流量增长
- 内容复用：一鱼多吃——一篇深度内容拆解成全平台素材
- 转化文案：说服性文案、A/B 测试变体
- 数据分析：内容分析、互动优化、ROI 度量

他的成功指标定得很硬：全平台平均互动率 25%、品牌视频平均完播率 70%、内容驱动线索增长 300%、内容投资回报 5:1。这不是"发出去就算完成"的选手。

## 什么时候雇佣他

| 场景 | 痛点 | 他能做什么 |
|------|------|-----------|
| 内容发布全靠灵感 | 有一搭没一搭，无法持续 | 编辑日历 + 内容支柱体系，让产出可规划 |
| 品牌各平台声音不统一 | 博客像论文、社媒像段子 | 品牌声音文档 + 全渠道一致性维护 |
| 一篇内容只发一个地方 | 生产成本高、覆盖面窄 | 复用策略：白皮书拆成图文/短视频/播客/邮件 |
| 有流量没线索 | 内容好看但不转化 | 转化型文案改写 + CTA 与线索捕获路径设计 |
| 想做 UGC 但无从下手 | 用户不产内容 | UGC 活动设计与社区参与机制 |
| 播客/视频想起步 | 不知道做什么选题 | 播客策略、视频脚本与缩略图优化方向 |

## 实战案例

### 案例一：一篇行业白皮书的"一鱼多吃"

一家 B2B SaaS 公司花了三周做了一份《2026 行业自动化趋势报告》，发完官网就沉了。他接手后做内容复用规划，把这份报告拆成一个月的全渠道素材：

```markdown
## 白皮书复用矩阵

| 衍生内容           | 平台           | 形态     | 目标              |
|--------------------|----------------|----------|-------------------|
| 执行摘要图文       | LinkedIn       | 轮播图   | 高管触达 + 引流下载 |
| 3 个趋势解读短视频 | YouTube/TikTok | 60s 脚本 | 认知扩张          |
| "报告中没写的第4个趋势" | 博客        | 长文     | SEO 截流搜索词    |
| 数据点信息图       | Instagram/Pinterest | 静态图 | 分享传播          |
| 作者访谈播客       | 播客渠道       | 30 分钟  | 深度信任          |
| 邮件连载           | 邮件列表       | 5 封序列 | 线索培育 → 转化   |
```

注意"报告中没写的第 4 个趋势"这条：把最有钩子的增量观点留在博客，而不是把报告原样搬过去——搜索流量进来才有理由停留。邮件序列则按线索培育节奏排布，最终以报告下载为转化锚点。同一份核心资产，六个渠道各取所需，边际生产成本极低。

### 案例二：编辑日历让内容从"救火"变"排产"

另一个客户的内容团队每周一都在为"这周发什么"开会扯皮。他先建立内容支柱（content pillars）再排日历：

```markdown
## 内容支柱体系（示例：开发者工具品牌）

- 支柱 A · 教育向（40%）：教程、最佳实践、避坑指南 → 目标：SEO + 信任
- 支柱 B · 观点向（30%）：行业评论、反共识分析 → 目标：互动 + 分享
- 支柱 C · 产品向（20%）：案例研究、功能故事 → 目标：转化
- 支柱 D · 社区向（10%）：用户故事、UGC 转发 → 目标：归属感

## 编辑日历（周视图）
| 周一      | 周三      | 周五      | 周日      |
|-----------|-----------|-----------|-----------|
| A 教程长文 | B 观点推文串 | C 案例视频 | D UGC 转发 |
```

支柱配比不是拍脑袋：教育向内容撑搜索流量基本盘，观点向制造传播峰值，产品向只占两成——因为"用户来是为了价值，不是来看广告"。每个支柱绑定量测指标，月度复盘时按数据调配比，而不是按感觉。

## 使用技巧

- 开场先给他受众画像和业务目标，他的内容支柱设计完全取决于"给谁看、要什么结果"
- 要求他给 A/B 变体：标题、开头钩子、CTA 都可以让他出 2-3 版做测试，这是他技能树里的标配
- 视频类需求连缩略图方向一起要：他有专门的 thumbnail optimization 能力，别浪费
- SEO 内容要提前给他目标关键词清单，他会在结构层面（标题层级、内链、格式）做搜索友好化
- 播客需求分两步走：先要策略文档（定位、选题池、嘉宾框架），再要单集脚本，一次性要全容易失焦
- 他的指标承诺（25% 互动率、70% 完播率）是北极星而非保证，实际基线因行业而异，让他先做基线测量再定目标
