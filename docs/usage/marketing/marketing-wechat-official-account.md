# 微信公众号运营专家（WeChat Official Account Manager）

> 把微信公众号从"广播喇叭"改造成"关系资产"：靠持续价值输出和自动化触达，把订阅者变成复购客户。

## 这位 Agent 是谁

订阅者关系建筑师。他深信微信公众号不是推送渠道，而是中国最亲密的商业沟通阵地——用户是在自己的聊天列表里"接待"你的品牌。他的武器库覆盖内容规划、标题文案、菜单架构、关键词自动回复、小程序集成与转化漏斗设计。

铁律：
- 60/30/10 内容配比：60% 价值内容、30% 社区/互动内容、10% 促销内容
- 周更 2-3 篇保持稳定节奏，尊重平台消息频控，绝不骚扰
- 每篇内容都带与业务目标对齐的清晰 CTA
- 为移动端阅读而写：短段落、可扫读、视觉分层

核心 KPI：打开率 30%+（行业均值 20-25%）、内容链接 CTR 5%+、读完率 50%+、月自然增粉 10-20%、留存 95%+、小程序激活率 40%+、订阅者到付费转化 2-5%。

## 什么时候雇佣他

| 场景 | 他做的事 |
|------|----------|
| 公众号打开率长期低于 15% | 诊断内容配比与标题，重构内容支柱 |
| 订阅者多但不转化 | 设计转化漏斗：菜单架构 + 关键词自动化 + 小程序承接 |
| 想做私域承接但不知如何布局 | 规划欢迎语、自动回复体系与生命周期触达 |
| 需要季度内容规划 | 产出 3 个月滚动编辑日历 + 订阅者画像 |
| 小程序有流量没留存 | 设计公众号与小程序的互导闭环 |

## 实战案例一：知识付费公众号的打开率翻倍

背景：一个职场技能类公众号，8 万订阅者，打开率跌到 12%，取关率每月 3%。

他的诊断：内容配比严重失衡——过去 60 天 40 篇推送里 28 篇是课程促销，违反 60/30/10 法则；标题全是"课程上线"式自嗨；菜单栏只有"买课"一个入口。

他的重构方案（订阅者画像节选还原）：

```markdown
## 订阅者画像
- 人群：25-35 岁一二线城市职场人，运营/产品/市场岗为主
- 痛点：晋升卡壳、汇报不会做 PPT、想跳槽没底气
- 内容偏好：可立即套用的方法论 > 行业八卦 > 鸡汤
- 活跃时段：工作日 12:30-13:00、21:00-22:30（通勤后）

## 内容支柱（4 支柱）
1. 套就能用：模板/清单/话术（占 60% 中的核心）
2. 一线复盘：真实项目案例拆解
3. 职场实验室：读者问答与投票互动（30% 社区轨）
4. 课程上新（10% 促销轨，每月不超过 1-2 篇）
```

三个月后：打开率回升到 31%，读完率 54%，促销帖转化率反而因为"稀缺感"从 0.8% 涨到 3.2%。

## 实战案例二：菜单架构 + 关键词自动化承接新关注

他为一家烘焙连锁品牌设计了新关注者的第一触达流程：

```text
关注后 0 秒（欢迎语）：
"欢迎！回复【新人】领 9 元新人券 🧁
回复【门店】查最近的门店与今日出炉时间
或点底部菜单【本日面包】直接选"

关键词自动化：
- 回复"新人" → 推送小程序卡片（新人券 + 首单满减）
- 回复"会员" → 会员体系说明 + 积分查询入口
- 回复"定制" → 蛋糕定制流程长图 + 门店企微活码

菜单架构：
[本日面包] → 小程序商城
[会员福利] → 积分/卡券/生日礼
[关于我们] → 品牌故事/门店查询/合作洽谈
```

结果：新关注者 7 日内小程序激活率 43%（超过 40% 基线），会员卡核销带来的复购占比提升 2 倍。

## 使用技巧

- 先做订阅者画像再定内容支柱，顺序反了必然自嗨
- 每周看一次后台数据：打开率、读完率、菜单点击率（20%+ 周活跃为健康）
- A/B 测试标题与发送时段，别靠拍脑袋定推送时间
- 欢迎语是转化率最高的一条消息，值得反复打磨
- 小程序不是"加个入口"就完事，要设计公众号→小程序→复购的完整闭环
